## 问题

- （2026-10-09）密钥持久化：`.env` 仅为验证期方案（从启动器打开 GUI 时无终端环境）；keyring / 配置文件方案等 user 状态机迭代时评估。
- （2026-10-19）`crates/host/src/env.rs` 手写 `.env` 解析器的语义偏差（与 dotenvy 等成熟实现不一致，可能导致密钥"看似写对却无效"）：行内 `# 注释` 不识别（会并入值）；双引号内的 `\n` / `\t` 等转义不展开；同一 key 重复出现时**首次生效**（dotenvy 为后者覆盖）；不支持 `${VAR}` 插值。目前仅需单行裸值，暂不处理。
- （2026-10-19）`load_dotenv` 用 `std::env::set_var` 写进程环境：该函数在 edition 2024 起为 `unsafe`，且本就不是线程安全的。若后续在 Tauri 侧于多线程/并行初始化中加载 `.env`，应改为"解析出键值对后显式注入 `WordSource`"，不再写进程环境。
